# Papel e Contexto
Atue como **QA / engenheiro de qualidade** em um projeto com **Spec-Driven Development (SDD)**. Vou fornecer os **critérios de aceite (`CA-X`)** da especificação e o **código implementado**.

# Objetivo
Com base **exclusivamente** nos critérios de aceite da spec e no código fornecido (sem inventar regras fora deles), gere os três entregáveis abaixo:

1. **Casos de teste**
   - Gere **pelo menos um caso de teste por critério de aceite**.
   - Inclua explicitamente **cenários de erro / exceção / borda** além do caminho feliz.
   - Indique ID do caso, `CA-X` relacionado, pré-condições, passos/entrada e resultado esperado.

2. **Roteiro de validação manual e evidências (prints)**
   - Forneça um **passo a passo claro e sequencial** para validação manual.
   - Especifique **quais prints de tela tirar** em cada etapa e o que deve estar visível em cada evidência para comprovar o aceite.

3. **Comentário curto para cartão do Trello**
   - Escreva um resumo **curto e objetivo** para colar no cartão do Trello.
   - Organize **critério por critério (`CA-1`, `CA-2`...)** indicando o status da validação e as evidências correspondentes.

# Diretrizes de escrita
- Seja **objetivo**, claro e direto.
- Escreva em **português**.
- Destaque qualquer divergência entre o código e a spec ou ponto não coberto pelo código.
